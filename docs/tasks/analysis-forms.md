# Задание: раздел «Анализ» в расширении РеестрБазФикс (облачная сессия)

Контекст: `docs/tasks/perf-analysis-proposal.md` (план), `docs/tasks/monitor-logcfg-ref.md` (как 1С-Монитор пишет ТЖ).
Формат исходников — EDT (`src/**/*.mdo`, `.form`, `.bsl`). Префикс новых объектов `рбф`. Тексты, комментарии, ответы — по-русски.
В облаке нет EDT и ИБ: правь файлы, повторяя формат соседних объектов (новые UUID — уникальные). Загрузка в ИБ и проверка EDT — локально, не твоя задача.
Уже есть (коммит e8ee06e): регистр `рбфЗаданияАнализаТЖ`, функции `ПоставитьАнализТЖ` / `ВзятьЗаданиеАнализаТЖ` / `ПринятьРезультатАнализаТЖ` в `ПравилаРеестраБаз`, HTTP `rbf-admin` tj-job/tj-result/tj-analyze. Не ломай.
Данные: `рбфСобытияТЖ` (Час, Сервер, База, Событие, КлючХеш → Ключ, Количество, ДлительностьСуммаМс, ДлительностьМаксМс, Пример), `рбфСчетчики`. Посмотри отчёты `рбфПроблемыТЖ`, `рбфНагрузкаСерверов`.

## Сделать — дизайн как в 1С-Мониторе (код закрыт, повторяем компоновку)
Общая шапка: период (список «Последние 3 часа» / «Сегодня» / «Произвольный интервал» + две даты + выбор периода), «только время с … по …», поле «База», «Обновить», ссылка «Доп. фильтр».
1. **Запросы**: слева группировка «% | Контекст / Запрос | Сек. | Кол.» (доля суммарной длительности), справа выполнения выбранной группы «Сек. | Дата выполнения | Пользователь»; внизу страницы «Контекст | SQL | 1С | Параметры | Сведения | План | Рекомендации», «Открыть в отдельном окне».
2. **Блокировки** (TLOCK/TTIMEOUT) и **Взаимоблокировки** (TDEADLOCK): слева «Объекты | Количество», справа список по дате; внизу слева «Схема» (табличный документ кто кого ждал) | «Граф XML» | «Рекомендации», справа «Сведения | Контекст | SQL | 1С» с полями Таблица, Индекс, Пользователь, Компьютер, Гранулярность.
3. **Ошибки ТЖ**: группировка по тексту с количеством, справа экземпляры, внизу подробности.
4. **График**: сверху таблица показателей (флажок, Показатель, Ось X, Ось Y, Масштаб), снизу диаграмма; показатели — рбфСчетчики и количество/длительность событий ТЖ по часам.
5. **ИИ-анализ ТЖ**: Каталог (UNC), период, «Пробный прогон», «Анализировать» (`ПравилаРеестраБаз.ПоставитьАнализТЖ`), список заданий со статусом, Сводка и Диагноз (JSON-массив severity/title/evidence/cause/fix/verify — таблицей).
6. Подсистема/раздел «Анализ» в командном интерфейсе; права — как у существующих отчётов.
Нет данных (схема, план, параметры) — страница с подписью «нет данных: нужен tj-analyzer», данные не выдумывать.
